Setup panel admin

Hanya perlu sekali. Setelah ini kamu cukup memakai password.

Buat token GitHub dulu:
  1. Buka GitHub → Fine-grained token baru.
  2. Isi nama bebas, misalnya panel portofolio. Pilih masa berlaku (maks. 1 tahun).
  3. Repository access: Only select repositories → pilih .
  4. Permissions → Repository → Contents: Read and write.
  5. Klik Generate token, salin, lalu tempel di bawah.

Minimal 10 karakter. Pakai gabungan huruf, angka, dan simbol.
